# Marked Topics Review Hub

This page is the permanent home for topics, terms, and phrases marked during timed mock exams because they felt unclear while solving.

Open `marked-topics.html` for review. The left contents bar works as the "sandwich" navigation: use it to jump through the accumulated explanations in alphabetical order.

## How This Page Grows

1. During a timed mock exam, use **Mark learning gap** on any question where a term, topic, option, or phrase feels unclear.
2. After submitting the exam, export the results JSON and move it into `question-bank/results/`.
3. Ask the agent to score or log the exam. The agent reads the `learningMarkers` in the results file and updates this page.
4. If the same topic appears again later, the explanation is improved and the new exam context is added under the existing topic instead of creating a duplicate.

## Entry Format

Each marked topic should use this structure so later review stays fast:

- **Simple meaning:** one clear explanation in plain language.
- **ISTQB meaning:** the official CTFL v4.0.1 wording or syllabus-aligned interpretation.
- **Why I marked it:** the confusion or wording that triggered the marker.
- **Exam example:** how this can appear in a question.
- **Do not confuse with:** nearby concepts that look similar.
- **Memory hook:** a short recall cue.
- **Marked history:** exam IDs, question IDs, chapters, and dates where this came up.
