# Final Revision Sheet

A condensed, high-density pre-exam revision document. Rebuilt/expanded whenever `/review weak` runs, and appended to after every `/mock` exam with a dated results log.

Intended use: this is the document to skim the night before / morning of the exam — everything else in `chapters/` is the detailed backing material.

## How to Use This File

1. Run `/review weak` periodically as you finish chapters to keep this synced with `revision/weak-concepts.md` and `revision/common-confusions.md`.
2. Run `/mock` for full mixed exams; results and the resulting personalized revision plan get logged here.
3. In the final days before the exam, read only this file top to bottom.
