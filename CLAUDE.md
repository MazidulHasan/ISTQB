# CLAUDE.md

This project's full instructions live in [AGENTS.md](AGENTS.md) — read it before doing anything in this repo. It defines the study/clarify/practice/review/mock workflows, file structure, and writing rules for this ISTQB CTFL v4.0 study notebook.

Convenience slash commands that follow those workflows are in `.claude/commands/` (`/study`, `/clarify`, `/practice`, `/review`, `/mock`, `/mock-studied`), but the same requests also work as plain natural language (e.g. "study chapter 1.1"). `/mock` is the real, timed, full-syllabus HTML exam; `/mock-studied` is the quick chat-based mock scoped to studied chapters only — see AGENTS.md's two separate Mock Exam workflow sections.
